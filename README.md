# 方块原野 · VOXEL WILDS

原创浏览器体素沙盒，以 Minecraft 的自由探索与建造体验为灵感。使用原创程序化像素材质，不含官方素材。

- 160 × 160 × 64 方块世界，固定种子生成山地、河流、树林、矿石、地下空隙与可进入的小屋。
- 第一人称碰撞、跳跃、奔跑、游泳；创造模式飞行与无限方块。
- 持续挖掘、放置、九格快捷栏、背包、材料合成、工具升级。
- 简化生存模式：生命、饱食度、摔落伤害、苹果恢复、保留物品的重生。
- 昼夜、天空、云层、动物漫游、方块碎屑、环境音效、实时小地图。
- 浏览器本地自动存档、手动保存、JSON 导入导出、新世界种子。
- 键鼠与基础触屏控制。浏览器禁止鼠标锁定时可拖动环顾。

这是有限地图的单人沙盒原型，尚未实现联机、红石电路、敌对生物、流体传播或完整 Minecraft 合成规则。

## 本地运行

`node serve.mjs`，然后打开 `http://127.0.0.1:4178`。

`node --test tests/world.test.mjs` 运行确定性地形、存档修改及射线选取验证。

渲染库 Three.js 位于 dist/vendor，保留 MIT 许可证。游戏渲染不依赖外部 CDN。界面字体使用 Google Fonts，加载失败时自动回退系统字体。
